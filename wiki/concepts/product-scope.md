# 제품 범위

## 문제

유용한 게시글을 북마크해도 원문이 삭제·비공개 전환·계정 탈퇴로 사라진다. 게다가 X, Threads, Reddit에 흩어진 저장 위치 때문에 다시 찾지 못한다.

## 해결

링크를 넣으면 **본문 + 작성자 이어쓰기 + 미디어 + 원본 스냅샷**을 내 디스크에 복제하고, 한국어로 검색할 수 있는 상태로 만든다. 원문이 죽어도 내 사본은 읽을 수 있고, 화면에는 "원문 삭제" 표시만 붙는다.

## MVP 범위

- 수집: X, Threads, Reddit 공개 게시글 링크
- 저장: 본문, 작성자 연속 글, 부모 맥락, 인용, 미디어(30MB 이하), 원본 HTML/추출 JSON
- 읽기: 원문/번역 토글, 타래 순서, 미디어 뷰어, 태그·메모
- 찾기: 키워드 검색(한국어 부분 일치) + 플랫폼·미디어·태그·정렬 필터
- 유지: 수동 원문 재확인, 삭제·부분 수집·오류 상태 구분

## 비목표 (의도적으로 미룸)

- 의미 기반 검색(임베딩) — 텍스트는 이미 보존되어 있어 나중에 청킹만 얹으면 된다
- 로그인 세션을 이용한 북마크 자동 폴링
- 다중 사용자, 공개 공유, 모바일 앱
- 삭제 감지 스케줄러(현재는 수동 재확인)

## 성공 기준

개인용이므로 정량 지표 대신 세 가지를 만족하면 성공으로 본다.

1. 링크 3종이 30초 안에 저장된다.
2. 한국어 검색으로 원하는 글을 세 번 이내 시도에 찾는다.
3. 원문 삭제 후에도 본문과 미디어를 열람할 수 있다.

## 운영 전제

단일 사용자 로컬 서비스다. 인증이 없으므로 외부에 노출하지 않는다. tailnet 접근만 허용한다. → [결정 001](../decisions/001-single-user-local.md)

## 남은 위험
