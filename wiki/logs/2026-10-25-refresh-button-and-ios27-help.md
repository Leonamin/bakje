# 새로고침 버튼과 iOS 27 단축어 도움말

1. **새로고침 버튼**: 홈 화면 웹앱에는 브라우저 새로고침이 없어 라이브러리·수집 머리글에 버튼을 넣었다(`refresh-button.tsx`, 전체 새로고침). 당겨서 새로고침은 충돌 위험과 발견성 때문에 뒤로 미뤘다. 릴리스 `20261025T151213Z`.
2. **iOS 27 도움말 재작성**: Apple 문서만으로는 한국어 용어를 알 수 없어 실기기 캡처를 받아 1~6단계를 캡처 기반으로 바꿨다. 순서(동작 추가 → ⓘ → 공유 시트에서 보기), 동작 이름(`URL 콘텐츠 가져오기`), 본문 필드 `키` 입력을 바로잡았다. 릴리스 `20261025T154002Z`.
3. **원인 분석**: 단축어가 "URL을 입력해주세요."를 띄운 것은 서버 응답이었고, JSON `키` 칸이 비어 있어서였다. `url`을 채우자 저장까지 동작했다. 서버 코드는 바꾸지 않았다.
