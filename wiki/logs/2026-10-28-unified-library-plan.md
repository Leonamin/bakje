# 통합 자료 탐색 기획

사용자가 요청한 서비스 경계와 기획 문서를 작성했다. 박제 프로젝트를 기반으로 확장하고, 기능별 책임을 내부 모듈로 나누는 안이다. 서버·프로젝트 분리는 다른 앱의 공통 사용이 필요해질 때 검토한다.

문서에는 기본 저장소와 읽기 전용 연결 폴더, 공통 자료·구성요소·파일의 관계, 자료 입력 예시, 임베딩 버전 관리, 변경·연결 오류·삭제 처리, 탐색 화면과 단계별 완료 조건을 기록했다. 현재 코드에서 확인한 사실과 목표 구조를 구분했다. 세부 정책은 미확정으로 표시했다.

코드·DB·원본 파일·운영 서비스는 변경하지 않았다.
