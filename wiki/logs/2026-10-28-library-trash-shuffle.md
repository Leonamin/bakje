# 라이브러리 선택·휴지통·셔플

모바일 길게 누르기와 PC 선택 버튼, 현재 페이지 일괄 선택과 숨김·숨김 해제·삭제·삭제 취소를 추가했다. 휴지통은 7일이 지난 자료를 서버 시작 시와 매시간 정리한다. 연결 폴더 원본은 보존하며 tombstone으로 재등록을 방지한다. SNS 미디어는 다른 참조가 없을 때 정리한다. 원본 HTML 스냅샷은 자동 정리하지 않는다. 관련 묶음 편집·원본 정리 기록은 실제 삭제 시 되돌릴 수 없게 된다.

라이브러리와 검색 화면에 시드 기반 셔플을 추가했다. `pnpm test:trash`, 기존 라이브러리·정리 통합 테스트, 타입 검사·UI 린트·빌드를 통과했다. 임시 DB로 PC 선택·숨김과 휴지통 복구를 확인했고 모바일 크기에서 합성 터치로 길게 누르기를 확인했다. 실제 모바일 기기는 미검증이다.
