# 자료 묶음 편집과 선택적 원본 정리

사용자가 후속 항목 2·3인 묶음 편집과 원본 폴더 정리를 요청했다. 직접 업로드·OCR·영상 분석은 이번 범위에서 제외했다.

- 상세에서 구성요소 역할·언어·순서 편집, 분리, 같은 저장소의 자료 합치기, 최근 변경 되돌리기를 제공한다. 구성요소 ID·입력 해시와 기존 임베딩은 보존한다.
- 한 자료 또는 전체 저장소를 대상으로 원본 정리 계획을 작성하고 경로·크기를 확인해 적용한다. 원본 경로와 DB 참조를 갱신하고 공유 파일은 한 번만 이동한다. 인라인 텍스트·매니페스트를 생성한다.
- 파일별 내용 해시·전후 경로·체크포인트·실행 임대와 저장소 잠금으로 재시도·되돌리기를 지원한다. 읽기 전용 연결, 버전 충돌, 목적 파일 충돌, 외부 내용 변경, 루트 밖 경로를 차단한다.
- MCP 도구 7개를 추가해 총 25개로 확장했다. 원본 적용·되돌리기는 계획 검토 후 확인 매개변수를 요구한다.
- 새 공용 Dialog의 어두운 배경에서 텍스트가 어둡게 표시되던 테마 토큰을 수정했다.
- 임시 자료의 통합 테스트, 기존 라이브러리 테스트, typecheck·UI lint·프로덕션 빌드를 통과했다. 실제 브라우저에서 묶음 편집과 원본 정리 적용·복구, 390px 화면, 읽기 전용 적용 차단을 확인했다. 실제 HTTP MCP의 새 도구와 확인 차단을 검증했다.
