# 019. 수동 박제 업로드 대신 자유 공유폴더

## Context

지원하지 않는 커뮤니티의 글을 사용자가 직접 박제하고 싶을 때가 있다. 사용자는 평소 AI에게 공유폴더 연결을 맡기거나 SNS 박제만 쓰며, 직접 박제는 드물다. 직접 업로드 화면(글·이미지·영상 묶음을 하나씩 추가)을 만들지 검토했다.

## Decision

직접 업로드 화면을 만들지 않는다. 수동 박제용 자유 공유폴더를 하나 두고 다음 순서로 처리한다.

1. 사용자(또는 AI)가 폴더를 만들고 글·이미지·영상 파일을 대충 넣는다.
2. AI에게 폴더 연결과 등록을 시킨다(`connect_library_folder`, `register_library_items`).
3. 이후 정리·분석은 기존 라이브러리 기능이 다른 공유폴더와 똑같이 처리한다.

## Consequences

- 업로드 화면·검증·용량 처리·모바일 대응을 만들지 않는다.
- 새 파일 반영과 임베딩 시작 시점은 미검증이다. 새 파일은 다시 등록을 시켜야 할 수 있다.
- 이 방식이 불편해지면 단일 업로드 화면을 만든다. 입력은 "제목 + 파일 여러 개"이고 묶음 종류(글·이미지·영상)는 확장자로 자동 판단한다. 종류별 업로드 화면은 만들지 않는다.

## Status

Accepted
