# 001. 단일 사용자 로컬 서비스

## Context

게시글 아카이브는 작성자 핸들, 비공개로 저장한 글, 개인 메모를 담는다. 다중 사용자로 만들면 인증·권한·격리·요금이 붙고, 개인용 도구로서 얻는 것이 없다.

## Decision

단일 사용자, 단일 인스턴스로 한정한다. 인증을 구현하지 않고 네트워크 노출도 하지 않는다. 접근은 호스트 로컬과 tailnet으로 제한한다.

저장소는 SQLite + 로컬 파일로 충분하다. Postgres나 오브젝트 스토리지를 도입하지 않는다.

## Consequences

- 인증·세션·사용자 모델이 없어 구현과 운영이 단순하다.
- 데이터 백업은 운영자 책임이다. `/var/lib/bakje`를 통째로 보관하면 된다.
- 실수로 공인 인터페이스에 바인딩하면 아무나 열람할 수 있다. `127.0.0.1` 바인딩과 tailnet 프록시만 사용한다.
- 향후 다중 사용자 요구가 생기면 `source` 소유자 컬럼과 인증 계층을 새로 설계해야 한다.

## Status

Accepted
